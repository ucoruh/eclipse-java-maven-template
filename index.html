Calculator App

eclipse-java-maven-template

A Java + Maven course-project template: JUnit 5 tests, JaCoCo and ReportGenerator coverage (both families, side by side), Doxygen and Javadoc API docs, and a full mvn site - the starting point for a CEN207 / CEN206 / CEN429 term project.

Download the latest release View on GitHub Read the README

Every report below is generated by 7-build-app.bat / 7-build-app.sh and shown inside this site in its own page. Not sure what a report shows or why some show up twice? Start with Which report is which?.
