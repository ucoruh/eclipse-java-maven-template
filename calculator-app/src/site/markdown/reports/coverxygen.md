<p class="report-explainer">How much of the public API has a Javadoc comment. <a
href="https://github.com/psycofdj/coverxygen">coverxygen</a> reads the Doxygen XML and turns it into an
<code>lcov.info</code> file, which <code>genhtml</code> (from the <code>lcov</code> package) then renders as an
HTML "coverage" report - except the thing being covered is documentation, not tests. See <a
href="coverxygen-reportgenerator.html">the ReportGenerator rendering</a> of the exact same data.</p>
