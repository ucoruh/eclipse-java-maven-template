# API docs

The API is documented with the Java-native **Javadoc** and with **Doxygen** (the tool the C/C++ and C# course
templates use), and the sources are browsable as **JXR cross-references** - on each platform, each one in a frame.

Documentation coverage (how much of the API has a doc comment) is under **Reports** for each platform.
