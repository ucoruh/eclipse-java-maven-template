Detailed Description

This class represents the main application class for the Calculator App.

The CalculatorApp class provides the entry point for the Calculator App. It parses three command-line arguments (operand, operator, operand), computes the result with Calculator and prints it. It never reads from standard input, so it is safe to run from a non-interactive script and to unit test directly.
